## Project Summary
**Objective:**  
To develop a steady-state process simulation and support a techno-economic assessment of propylene production via the Methanol-to-Propylene (MTP) Lurgi Process using Aspen UniSim. The work focused on flowsheet development, process representation, and evaluation of key operating parameters.

**Model type:**  
Steady-state (Aspen UniSim)
Fluid Package: Peng-Robinson / NRTL

## Key Steps
- Developed the Process Flow Diagram (PFD) representing the MTP Lurgi Process
- Specified feed and product streams based on project design assumptions
- Selected and configured relevant unit operations
- Performed mass and energy balance consistency checks
- Reviewed key outputs (stream properties, flowrates, and utilities where applicable)
- Contributed to the broader techno-economic evaluation framework

## Key Assumptions
- Steady-state operation
- Process conditions defined by project/case study scope
- Simplified representation suitable for preliminary design analysis

## Outputs Included
- PFD export / screenshot
- Selected stream table summary
- Supporting project notes
