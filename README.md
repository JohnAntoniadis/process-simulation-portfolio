# Process Simulation Portfolio (Honeywell UniSim)

This repository showcases selected academic process simulation work developed in **Honeywell UniSim** as part of Chemical Engineering coursework. The focus is on **steady-state process modeling**, 
**PFD development**, and **mass & energy balance analysis**.

## What you will find
- Process Flow Diagrams (PFDs) exported as images/PDFs
- Brief notes on scope, assumptions, and key outcomes
- Tools and skills demonstrated per project

## Projects
### 1) n-Octane Process Design (UniSim)
- Scope: Steady-state flowsheet development and preliminary process design
- Skills: PFD design, stream specification, unit operation integration, mass & energy balance checks
- Files: `projects/n-octane-process-design/images/`

### 2) Propylene Production via MTO (Lurgi) – Techno-Economic Study (UniSim)
- Scope: Flowsheet-based process representation supporting a techno-economic assessment
- Skills: Process modeling, flowsheet logic, scenario thinking (steady-state)
- Files: `projects/propylene-mto-lurgi/images/`

## Tools
- Aspen UniSim (steady-state simulation)
- Supporting analysis: Excel (mass/energy balance checks, simple sensitivity calculations)

## Notes & Disclaimer
These materials are **academic** and shared for portfolio purposes. No proprietary industrial data is included. UniSim simulation files are not provided; only exported diagrams and summaries are included.
